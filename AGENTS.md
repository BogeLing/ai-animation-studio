# Guide for agents working in this repository

This repository makes animated short films as code: the agent writes the scene, an engine renders it frame by
frame, and the sound is synthesized. Everything is generated by code, with no image, video or music models.

## Start here

- **Making, changing, rendering or delivering a film:** follow the `film-production` skill
  (`.claude/skills/film-production/SKILL.md`), which is the production loop, and the engine's own skill for
  the API: `engines/papermotion/.claude/skills/papermotion/SKILL.md` (the same skill is in
  `engines/papermotion/.agents/skills/`). Then read `engines/papermotion/AGENTS.md`.
- **Work from `engines/papermotion/`,** and use `corepack pnpm` when `pnpm` isn't on PATH.
- **Reuse before writing:** captions, title cards, hop walks, a morning-to-sunset sky, instant photos, a lo-fi
  score and paper foley are in `engines/papermotion/examples/shared/`. The `ubc` and `showcase` films use them all.

## Rules

- Keep `engines/papermotion/src/` close to upstream papermotion. Generic primitives go there with a test and
  an export; scene-level building blocks go in `examples/shared/`.
- Show the user key frames before a full render, and look at every image yourself first.
- Render one film at a time (`pnpm render:detached`), and run `tools/video/check_video.sh` on the result
  before sending it. Aim the mix at −16 LUFS integrated with the true peak under −1 dBFS.
- Before calling anything done: `pnpm typecheck` and `pnpm test` in `engines/papermotion/`.
- This repository is public. Keep private material out of it: someone's CV or voice, client logos, and
  personal paths or accounts.
